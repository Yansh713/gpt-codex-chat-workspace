# GPT–Codex Chat Workspace

把你与 GPT 的聊天记录放进 `chats/`。之后在 Codex 中打开这个仓库，并明确告诉 Codex 要读取哪份聊天、要完成什么工作。

## 推荐流程

1. 每次有一段值得保留的聊天，新建一个 Markdown 文件，例如：`chats/2026-09-23-研究想法.md`。
2. 用下面的模板记录：目标、完整对话、已经确认的决定、待办事项。
3. 在 Codex 里说：`请读取 chats/2026-09-23-研究想法.md，并按其中已确认的决定完成待办。`

不要把密码、验证码、API 密钥或私人敏感信息提交到仓库。
