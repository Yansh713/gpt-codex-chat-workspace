# 先进封装职业规划记录

## 目标

围绕“力学博士转向先进封装工艺/工艺研发/工艺整合”这一职业目标，系统明确以下问题：

1. 了解先进封装的主要技术方向，以及适合个人背景的切入点。
2. 明确先进封装相关项目到底应该做什么，尤其是在暂时无法实习的情况下，如何利用学校微纳加工中心开展可落地项目。
3. 将仿真定位为辅助工具，而不是未来职业发展的唯一核心能力。
4. 搜索并整理可直接学习、复现或改造成项目的开源资源，重点关注：
   - GitHub
   - Bilibili
   - YouTube
   - IEEE
5. 分析当前简历在先进封装求职中的优势、短板和表达问题。
6. 最终建立一个清晰的职业标签：
   > 实验型力学博士，具备微纳加工、界面与材料研究、FIB/SEM 失效分析能力，并逐步补齐 RDL、Cu Pillar、Flip-Chip、Underfill、Hybrid Bonding、DOE、Process Window、Yield 等先进封装工艺能力。

## 完整对话

### 用户

我今天去参加中电科中科芯的招聘会，我提到自己是力学专业的博士生，想投递封装设计、封装工岗位。他看了我的简历，说：我目前研究方向与封装设计、工艺岗位不太对口，比如研究异质界面力学虽然有公司在做，但是不是重点关心的工程问题。其次由于我后年才毕业，他建议我做一些相关的项目、实习，关于先进封装方面的。

我现在有几个问题：

1. 先进封装包括什么方向？
2. 他所说的先进封装相关的项目是指什么？是否有我目前可以尝试去做的内容，如果目前去不了实习的话？
3. 请你阅读我的简历，评价我目前的积累对于以后进军先进封装行业、岗位还有哪些不足，哪些地方可以弥补？

### 助手

结合你的简历和中科芯招聘人员的反馈，核心判断是：

你并不是“不适合先进封装”，而是目前的科研积累更多体现为：

- 力学
- 界面
- 微纳表征
- 材料
- 微纳加工

但还没有完整转化为企业视角下的：

- 封装结构
- 工艺流程
- 工艺窗口
- 可靠性
- 良率
- 工程问题闭环

你目前已经具备几个与先进封装高度相关的基础：

1. 微纳尺度界面/断裂力学
2. FIB/SEM/TEM 等失效分析能力
3. MEMS/微纳加工基础
4. 高分子/复合材料背景
5. 3D-IC 异质界面可靠性项目

真正需要补的是：

> 封装结构—工艺—多物理场—可靠性—制造输出

这一整条工程链。

先进封装可以按求职视角理解为：

- WLP / Fan-Out
- RDL
- Bumping / Cu Pillar
- Flip-Chip
- TCB
- Underfill
- 2.5D
- Interposer
- 3D IC
- TSV
- Micro-bump
- Hybrid Bonding
- Chiplet / Heterogeneous Integration
- Package Reliability
- Package FA
- Thermal / Mechanical Design
- SI / PI
- Packaging Integration

对于你来说，最适合的职业切入口并不是纯 Package Layout，而更可能是：

- 封装工艺
- 封装可靠性
- 失效分析
- 工艺研发
- 工艺整合
- Packaging Integration

当时建议的项目方向包括：

1. 2.5D / Chiplet 热机械可靠性与结构优化
2. TCB / Flip-Chip / Underfill 工艺窗口研究
3. Package Design 基础项目

但后续需要根据你的职业偏好进一步调整。

### 助手

职业方向重新明确以后，建议从“纯仿真导向”调整为“先进封装工艺导向”。

核心定位为：

> 仿真不是主标签，而是工艺研发中的辅助工具。

更加适合你的职业路线是：

```text
实验型力学博士
    ↓
先进封装工艺 / 工艺研发
    ↓
RDL / Cu Pillar / Flip-Chip / Underfill / TCB / Hybrid Bonding
    ↓
DOE / Process Window / Yield / Reliability / FA
    ↓
Advanced Packaging Process Integration
    ↓
Fabless / Foundry / OSAT 的高级封装开发
```

长期目标不是“纯仿真工程师”，而是：

> 懂材料、懂微纳加工、懂界面、能做失效分析、能建立工艺窗口的先进封装工艺工程师。

仿真的使用方式应为：

```text
实验发现
    ↓
简单模型 / 仿真解释
    ↓
DOE
    ↓
工艺窗口
    ↓
FA
```

而不是：

```text
全部工作 = 有限元仿真
```

#### 推荐项目 1：Flip-Chip Underfill 工艺窗口与失效研究

这是目前最适合的项目之一。

你已有的能力：

- 高分子物理
- 高分子加工
- DMA
- DSC
- 流变
- 界面力学
- FIB
- SEM

与 Underfill 高度相关。

可以设计 Dummy Flip-Chip Test Vehicle：

```text
Si Dummy Die
    ↓
Spacer / Cu Pad / SU-8 Micro-pillar
    ↓
Underfill
    ↓
Glass / Si / PCB Coupon
```

可研究变量：

- Gap Height
- Underfill Viscosity
- Dispense Temperature
- Dispense Pattern
- Surface Treatment
- Cure Temperature
- Cure Time

响应指标：

- Filling Time
- Void Ratio
- Delamination
- Interface Adhesion
- Residual Stress
- Thermal Cycling 后失效

可使用：

- 流变仪
- DSC
- DMA
- 光学显微镜
- SEM
- FIB

如果需要仿真，可以加入：

- COMSOL 毛细流动
- 简单固化模型
- 热应力分析

最终项目可命名为：

> 面向 Fine-Pitch Flip-Chip 的 Capillary Underfill 填充与固化工艺窗口开发

---

#### 推荐项目 2：Cu RDL 微纳加工 Test Vehicle

如果学校微纳加工中心具备：

- 光刻
- PVD / Sputtering
- Cu 电镀
- 干法刻蚀
- 湿法刻蚀
- 划片

则非常适合做。

项目名称可以是：

> 面向 Fan-Out / WLP 的 Cu RDL 工艺开发及可靠性 Test Vehicle

Mask 可以设计：

- Daisy Chain
- Kelvin Structure
- Different Line / Space
- Different Pad Size
- Different Via Size
- Different Cu Thickness
- Different Corner Geometry

基本工艺：

```text
Si / Glass Wafer
    ↓
Dielectric
    ↓
Lithography
    ↓
Ti/Cu Seed
    ↓
Cu Electroplating
    ↓
PR Strip
    ↓
Seed Etch
    ↓
Passivation
    ↓
Opening
    ↓
Electrical Test
```

DOE 变量：

- Current Density
- Plating Time
- Seed Thickness
- PR Thickness
- Pattern Density

响应：

- Cu Thickness Uniformity
- Surface Roughness
- Line Width Bias
- Open / Short Yield
- Sheet Resistance

表征：

- SEM
- FIB Cross-section
- Profilometer
- Four-point Probe
- Optical Inspection

#### 推荐项目 3：Cu Pillar / Micro-bump 电镀

如果微纳中心还有：

- 厚胶光刻
- Cu Electroplating
- Seed Layer PVD

则可以做：

> Cu Pillar Array Fabrication

设计不同：

- Diameter
- Pitch
- Height

研究：

- Current Density
- Plating Time
- Additive
- Pattern Density
- Flow Condition

分析：

- Pillar Height
- Height Uniformity
- Sidewall Morphology
- Surface Roughness
- Within-Wafer Uniformity

---

#### 推荐项目 4：Cu-Cu / Hybrid Bonding

Hybrid Bonding 很值得做，但设备要求高。

真正的 Hybrid Bonding 通常需要：

- CMP
- Plasma Activation
- High Precision Alignment
- Wafer / Die Bonder
- Annealing Furnace
- AFM / Profilometer
- 高洁净度

如果学校设备不足，不建议把普通 Cu-Cu 热压连接包装成 Hybrid Bonding。

更现实的项目是：

> Cu-Cu Thermocompression Bonding Test Coupon

研究：

- Surface Roughness
- Cleaning Method
- Surface Treatment
- Bonding Temperature
- Pressure
- Annealing
- Electrical Resistance
- Bond Strength

#### 简历修改建议

当前简历最大问题不是“内容少”，而是：

> 岗位相关信息权重不足。

招聘者第一眼更容易形成：

> 纳米材料 / 力学博士

而不是：

> 有微纳加工和失效分析能力，正在转先进封装工艺的博士。

建议调整结构：

```text
教育背景

先进封装与微纳工艺项目

核心技术能力

精选科研经历

代表性论文

荣誉
```

项目按岗位相关性排序，而不是完全按时间排序：

1. 3D-IC 封装异质界面可靠性
2. Flip-Chip Underfill 工艺项目
3. Cu RDL / Cu Pillar 项目
4. Polymer–Graphene 界面项目
5. 其他科研项目

3D-IC 项目应减少论文式表达，增加工程化信息：

- 具体界面
- 具体封装结构
- 工艺条件
- 失效模式
- 工艺优化
- 工程输出

例如：

> **3D-IC 封装异质界面可靠性研究**  
> 面向 3D-IC 中金属-金属 / 金属-高分子关键界面，利用 FIB 制备微纳测试结构，结合 SEM 原位加载与断裂力学分析界面裂纹萌生、扩展及失效行为；建立界面微观力学特征与封装可靠性的关联，为后续界面材料与工艺优化提供依据。

非封装科研应大幅压缩。

亚纳米项目的作用主要是：

- 证明科研能力
- 证明实验能力
- 证明论文能力

煤层气项目可从先进封装定向简历中删除。

技能部分应从“设备罗列”转为“问题解决能力”：

```text
先进封装与微纳工艺
失效分析
材料与界面表征
数据分析
```

设备型号不必占据过多篇幅。

未来真正做过以后，可以逐步加入：

- DOE
- SPC
- PFMEA / FMEA
- 8D
- Process Window
- Yield
- Defect Analysis
- Root Cause Analysis
- Reliability
- TCT
- HAST
- MSL
- Warpage
- Delamination
- Void
- RDL
- Bumping
- Cu Pillar
- Flip-Chip
- Underfill
- TCB
- Hybrid Bonding

原则：

> 没做过的不要提前写。

AI 工具不应作为先进封装简历独立核心模块。

如果后续用 Python 做 DOE、SPC、Yield Analysis、YAP 等，可以写为：

> 数据分析：Python，具备 DOE、工艺数据分析、统计分析及可视化能力。

最终希望招聘者在 10 秒内看到四个标签：

### 3. 项目优先级

目前优先考虑：

#### 第一优先级

**Flip-Chip Underfill 工艺窗口项目**

原因：

- 与现有高分子、界面、流变、DSC、DMA、SEM/FIB 能力匹配度最高；
- 工艺属性强；
- 容易形成 DOE、Process Window、Void、Delamination、FA 等工业关键词。

#### 第二优先级

**Cu RDL / Cu Pillar Test Vehicle**

原因：

- 能充分利用学校微纳加工中心；
- 可以真正获得光刻、沉积、电镀、刻蚀、表征、缺陷分析等工艺经历；
- 与 Fan-Out、WLP、Interposer 等先进封装高度相关。

#### 第三优先级

**Hybrid Bonding Yield Modeling + Cu-Cu 实验**

先从开源 YAP/YAP+ 入手。

如果学校设备条件允许，再做：

- Cu-Cu Bonding
- Surface Treatment
- Roughness
- Bond Strength
- Electrical Resistance
